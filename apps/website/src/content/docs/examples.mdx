These are the example projects from [`examples/`](https://github.com/UXCentury/open-bone/tree/main/examples), each one
`.obone` file running in [`<openbone-player>`](/packages/player/), the same web player you
[embed in your own site](/engines/web/). Nothing here is a video: the state machines react to your clicks, the
physics and particles are simulated in your browser, and the buttons under each player set its state-machine inputs.

Sound starts muted, because browsers only allow audio after a click. Press the speaker in a player's corner to hear it.
To open one in the editor, use **☰ Menu → Examples…** (see the [quick start](/getting-started/quick-start/)).
