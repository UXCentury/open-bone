# Pose Landmarker model

`pose_landmarker_full.task` is MediaPipe's Pose Landmarker (full) model, used by **Animate from video** to track the
body in a video or webcam clip. The editor bundles it (with the WASM runtime from `@mediapipe/tasks-vision`) so tracking
works offline and sends nothing to another server.
