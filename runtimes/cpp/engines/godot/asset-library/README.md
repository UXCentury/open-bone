# OpenBone for Godot (addon branch)

This branch is generated by [`.github/workflows/publish-godot.yml`](https://github.com/UXCentury/open-bone/blob/main/.github/workflows/publish-godot.yml)
from each published release; don't edit it by hand. It holds only the ready-to-install addon (`addons/openbone/`, with
prebuilt libraries), so that the Godot Asset Library's download of a commit stays small.

Source, documentation and issues: https://github.com/UXCentury/open-bone (the GDExtension lives in
`runtimes/cpp/engines/godot`).

Install: copy `addons/openbone` into your Godot 4.4+ project, or use the AssetLib tab in the editor. See
[addons/openbone/README.md](addons/openbone/README.md).
