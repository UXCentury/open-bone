# Plugins

Built, not committed. Released packages (the `upm` branch, OpenUPM, the release tarball) include the DLLs. In a
repository checkout, run `python3 runtimes/csharp/unity/build-package.py` from the repository root to put
`OpenBone.Runtime.dll`, `OpenBone.Scripting.Jint.dll`, `Jint.dll` and `Esprima.dll` here (see the package README).
