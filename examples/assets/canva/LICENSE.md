# Example art (this folder)

These illustrations were generated with Canva's AI image tools by UXCentury (the project owner), then cut into
parts for rigging. UXCentury owns them and releases them under the same MIT licence as the rest of this
repository, so you can reuse them with your own OpenBone projects.

| File | Used by |
|---|---|
| `knight-*.png` | `knight.obone` |
| `rocket.png` | `rocket.obone`, `crash.obone` |
| `crash-sky.jpg`, `explosion_000N.png` | `crash.obone` |
| `button-play.png` | `button.obone` |

Everything else in `examples/assets/` (cape, flame and smoke frames) is drawn by `examples/build-examples.ts`.
