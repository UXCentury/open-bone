# @openbone/render-canvas

Canvas 2D renderer for OpenBone: draws a posed skeleton to a browser canvas or a headless one (for example `@napi-rs/canvas` in Node), used by the editor and for PNG/GIF exports.

Part of [OpenBone](https://github.com/UXCentury/open-bone), open-source 2D skeletal animation with interactive state machines and an MCP server. MIT licensed.

## Install

```bash
npm install @openbone/render-canvas
```
