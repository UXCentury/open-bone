# @openbone/scripting

Runs the scripts attached to OpenBone state machines in a QuickJS (WebAssembly) sandbox: `createQuickJsHost()` returns a `ScriptHost` for `@openbone/runtime`.

Part of [OpenBone](https://github.com/UXCentury/open-bone), open-source 2D skeletal animation with interactive state machines and an MCP server. MIT licensed.

## Install

```bash
npm install @openbone/scripting
```
