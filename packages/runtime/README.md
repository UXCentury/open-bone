# @openbone/runtime

The reference OpenBone runtime, renderer-agnostic: posing, constraints (IK, transform, path, physics), animation mixing, state machines with listeners, events, particles, text and audio commands. Pair it with a renderer such as [`@openbone/render-webgl`](https://www.npmjs.com/package/@openbone/render-webgl) or use [`@openbone/player`](https://www.npmjs.com/package/@openbone/player).

Part of [OpenBone](https://github.com/UXCentury/open-bone), open-source 2D skeletal animation with interactive state machines and an MCP server. MIT licensed.

## Install

```bash
npm install @openbone/core @openbone/runtime
```
