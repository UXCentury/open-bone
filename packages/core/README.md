# @openbone/core

The OpenBone document model: types, the JSON (`.obone`) and binary (`.obonb`) formats, validation, the edit ops shared by the editor, CLI and MCP server, undo history and atlas data. `@openbone/core/lite` is the same without the op registry and its zod dependency, for players.

Part of [OpenBone](https://github.com/UXCentury/open-bone), open-source 2D skeletal animation with interactive state machines and an MCP server. MIT licensed.

## Install

```bash
npm install @openbone/core
```
