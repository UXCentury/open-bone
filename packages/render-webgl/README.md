# @openbone/render-webgl

Batched WebGL2 renderer for OpenBone, with stencil clipping, blend modes and two-colour tint.

Part of [OpenBone](https://github.com/UXCentury/open-bone), open-source 2D skeletal animation with interactive state machines and an MCP server. MIT licensed.

## Install

```bash
npm install @openbone/render-webgl
```
