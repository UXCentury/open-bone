# @openbone/export

Encoders for OpenBone exports: PNG, APNG, GIF, PSD, AVI and MOV (Motion-JPEG), ZIP, sprite sheets and engine packs for Unity, Godot, Flutter and generic engines.

Part of [OpenBone](https://github.com/UXCentury/open-bone), open-source 2D skeletal animation with interactive state machines and an MCP server. MIT licensed.

## Install

```bash
npm install @openbone/export
```
